## Overview

***aspirational — not yet implemented***

The **StoryHearth Game Engine™** is a game engine for building 3D narrative-driven role-playing experiences. It is designed to be flexible and modular, with its features being opt-in, allowing for a wide range of game types and styles within the larger scope of what it is capable of. Games may include both action and non-action RPG elements, social simulation elements, life simulation elements, and visual novel elements, all with strong support for adaptive narratives. It supports a variety of 1st and 3rd person control styles and does not prescribe a specific art style or genre, though it is being developed with a focus on 3D fantasy RPGs with life and social sim elements and strong narrative elements using a realistic art style. The engine is built with extensibility in mind, allowing developers to create their own custom systems and mechanics on top of the core framework.

**Stories by the Hearth™** is a game series built using the StoryHearth Game Engine™, focused on immersive storytelling and character identity.

Both the engine and the series are under active development and may evolve significantly over time.

## Goals

The end goal of this project is to create a flexible, modular, and user-friendly framework for building narrative-driven 3D RPG games, while also developing a compelling game series both as a product and as a demonstration of the game engine's capabilities. My personal goal is to both A) tell my story and B) enable others to tell theirs using the shared tools and resources that I create.

The StoryHearth Game Engine is being developed in parallel with the *Stories by the Hearth* game series, with the games produced evolving in scope and complexity over time as the engine develops. While the StoryHearth Game Engine will be completely open-source except for a few brand-related assets, the games in the *Stories by the Hearth* series will include a mix of open-source and proprietary assets, with the proprietary assets being those that are directly related to the branding and unique elements of the series. They'll be included in the source (both for modding and so you can see how they work), but not licensed for redistribution or reuse outside of the series. Security sensitive assets (if any) will be kept in a private repository and not included in the source at all (example versions of these assets may or may not be).

Not all games built with the StoryHearth Game Engine will be part of the *Stories by the Hearth* series. The first few games will likely be throw away prototypes meant to test systems as they are developed. In the future, the StoryHearth Game Engine and the *Stories by the Hearth* series are likely to be split into separate repositories.
